# _🛍️_ NovaCart

NovaCart is a modern e-commerce web application built with React.js, designed to provide a smooth and user-friendly online shopping experience.

The project focuses on building an interactive shopping interface with reusable components, efficient state management, and a clean, responsive design.

### 🌐 Live Demo

[View Live Website](https://novacartecommerce.netlify.app)

### 📂 GitHub Repository

[View Source Code](https://github.com/Fizza721/novacart)

### 🛠️ Technologies Used

React.js – Building reusable and interactive UI components.

JavaScript (ES6+) – Application logic and functionality.

React Router – Navigation and routing between pages.

CSS – Styling and responsive layouts.

Authentication – User login and signup functionality.

Vite – Development environment and build tool.
